# Austin Climate Trends

A small, reproducible climate analysis project built around historical weather observations for Austin, Texas.

## Project resources

- [Repository README](https://github.com/davilo61/austin-climate-trends/blob/master/README.md)
- [Climate analysis notebook](https://github.com/davilo61/austin-climate-trends/blob/master/notebooks/climate_analysis.ipynb)
- [Austin climate exploration notebook](https://github.com/davilo61/austin-climate-trends/blob/master/notebooks/austin_climate_exploration.ipynb)

The sample Austin values are illustrative and intended for demonstration, not as an official climate record. Use a trusted station dataset when producing research results.
